# Odin Project – Admin Dashboard

This repository contains my submission for the **Admin Dashboard** project from [The Odin Project](https://www.theodinproject.com/) curriculum.

## Project Overview

The Admin Dashboard project is a practice exercise in building a fully-responsive dashboard layout using **HTML** and **CSS Grid**. The goal is to recreate a multi-panel admin interface with a sidebar, header, main content area, and sidebar widgets.

## Features

- Responsive admin dashboard layout built with CSS Grid
- Sidebar navigation with icon links
- Header with search bar and user info
- Projects card grid in the main content area
- Announcements and trending panels

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox)

## Live Demo

Open `index.html` in your browser to view the dashboard.
